# vim-key-trainer

Python과 PySide6로 만드는 데스크톱 Vim 타자연습 게임입니다. 다음 세 단계로 학습하고, 별·개인 기록과 소리·화면 효과로 재도전합니다.

| 단계 | 화면과 진행 방식 |
| --- | --- |
| 숫자·기호 | 기본 20자 등 10~20자 이상의 숫자·기호를 한꺼번에 보고 앞에서부터 계속 타이핑합니다. 다음 문자열이 자동으로 이어지며 정해진 총 길이를 채우면 완료합니다. |
| Vim 명령 | `8ciw`, `22gg`, `qa`, `"+y` 같은 명령 항목을 여러 개 나열합니다. 현재 입력 중인 항목을 강조하고 그 의미를 하단에 보여 줍니다. |
| 문서 수정 | 왼쪽은 수정 전에서 시작하는 현재 문서, 오른쪽은 고정된 목표 문서입니다. 하단 가이드를 따르거나 지원 명령으로 자유롭게 풀고, 목표를 달성하면 기준 풀이와의 입력 횟수 차이·수정 시간을 확인합니다. |

자유 풀이에서는 가이드와 다른 유효한 풀이도 정답입니다. 결과에 사용자 입력 `K`, 검증된 기준 풀이의 입력 `B`, 차이 `K - B`를 표시합니다. 기준 풀이보다 적게 입력해도 정답으로 인정하며, 기준을 모든 가능한 풀이 중의 절대 최단이라고 가정하지 않습니다.

키 입력과 문서·커서·모드 변화는 Python 내부에서 처리합니다. 실제 Vim/Neovim 실행·임베딩·연동을 사용하지 않으며 사용자 파일을 편집하지 않습니다.

2단계는 명령의 키와 뜻을 익히는 타이핑 연습이므로 3단계에서 아직 실행하지 않는 명령도 다룹니다. `qa`, `"+y`처럼 맥락이나 추가 입력이 필요한 항목은 이를 함께 안내하며 실제 매크로 기록·클립보드 복사는 하지 않습니다.

정답·오타·명령 완료·문서 완성·기록 갱신에 짧은 효과음과 화면 효과를 제공합니다. 소리는 기본 끄기이며 켜기·끄기·음량·모션 줄이기를 설정할 수 있습니다. 무음에서도 같은 학습 피드백을 보여 줍니다.

초기 실행 의존성은 Python 3.12 환경에서 설치합니다.

```sh
python -m pip install -r requirements.txt
```

`PySide6`는 GUI·입력·애니메이션·효과음, `pydantic`은 레슨·설정 검증, `platformdirs`는 로컬 기록 경로에 사용합니다. 이 게임 범위에는 별도 게임 엔진이 필요하지 않습니다. M0에서 `pyproject.toml`·`uv.lock`과 개발 도구를 구성합니다.

Python 3.12/macOS arm64에서 의존성 dry-run을 확인했습니다. 실제 설치·GUI 실행·다른 OS 검증은 아직입니다. 구현 후 실행 명령은 `vim-key-trainer`, 모듈 이름은 `vim_key_trainer`를 사용합니다.
