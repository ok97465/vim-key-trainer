# vim-key-trainer

Python·PySide6 기반의 데스크톱 Vim 키보드 연습기입니다. 계정·서버·Vim 설치 없이 로컬에서 동작하며, 연습 중 사용자 파일을 변경하지 않습니다.

## 설치와 실행

Python 3.12와 [uv](https://docs.astral.sh/uv/getting-started/installation/)를 준비한 뒤 실행합니다.

```sh
uv sync --dev
uv run vim-key-trainer
```

모듈 실행은 `uv run python -m vim_key_trainer`입니다. uv 없이 macOS/Linux에 설치하려면 다음 명령을 사용합니다.

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/python -m vim_key_trainer
```

## 연습

왼쪽 메뉴에서 분야와 레슨을 고른 뒤 **연습 시작**을 누르거나 Enter로 시작합니다. 결과 화면에서는 밝게 강조된 **다른 문제**가 먼저 표시되며, Enter로 다음 문제를 준비할 수 있습니다.

| 분야 | 내용 |
| --- | --- |
| 숫자·기호 | 숫자·Shift 기호·괄호·따옴표 등을 연습합니다. 기본 20자씩 표시하고 총 100자를 입력합니다. |
| Vim 명령 | 문법에 맞는 명령을 10개씩 계속 생성합니다. **연습 마치기**를 누르면 입력 중인 명령을 마친 뒤 결과를 표시합니다. |
| 문서 수정 | 공개 문서 16개의 복구 연습과 숫자·줄·단어·메모·복합·undo의 6유형 생성 연습을 제공합니다. |

숫자·기호와 Vim 명령은 정확도·활성 시간·콤보·별·개인 기록을 표시합니다. 명령 타이핑은 편집·매크로·클립보드 동작을 실행하지 않습니다.

### 문서 수정

**실제 문서 연습**은 포함된 원문의 일부를 손상시키고 고정된 원문으로 복구합니다. 기본 수정량은 7곳입니다. 원문에서 적용 가능한 기술과 위치를 함께 골라 비중을 반영합니다. **무작위 문서로 연습 준비** 또는 연습 화면의 문서 선택 콤보박스로 원문을 고릅니다. **원문·라이선스**에서 출처와 허용 라이선스를 확인할 수 있습니다.

**기술별 생성 연습**은 12·24·40줄에서 각각 7·7·10곳을 수정합니다. 단어·표식 정리는 삭제·변경·객체 범위를 고르게 섞습니다. 복합 연습은 이동·검색·치환·복사·범위 선택·변경 반복 등을 설정한 비중으로 섞습니다. 같은 기술의 괄호 표기·별칭은 하위 변형으로 다룹니다. undo 유형은 가이드 전용입니다.

**연습 설정 → 문서 수정의 기술 비중**에서 10개 기술의 상대 비중을 조절합니다. 기본값은 이동·찾기 6, 단어·객체 5, 치환 1처럼 이동과 단어 편집에 더 많은 비중을 둡니다. 합계를 100에 맞출 필요는 없고, 0은 해당 기술을 중심 과제에서 제외합니다. 비중은 키 입력 횟수의 비율이 아니므로 필수 이동·입력은 다른 과제에도 함께 나옵니다. 숫자·단어 등의 집중 연습은 해당 학습 목적을 유지합니다.

**가이드**는 기대 키를 따라 입력하고, **자유 풀이**는 목표 문서에 도달하는 다른 유효한 해법도 인정합니다. 가이드는 글자·단어를 많이 세는 대신 보이는 구분자 찾기, `;`·`,`로 찾기 재사용, 읽을 수 있는 문구 검색과 객체 수정을 활용합니다. 결과에는 입력 횟수·기준 입력 횟수·소요 시간을 표시하며, 기준보다 짧은 풀이도 인정합니다. 두 모드의 별과 개인 기록은 따로 관리합니다.

현재 문서는 커서 줄에 절대 줄 번호, 나머지 줄에 상대 줄 번호를 표시합니다. 목표의 **노랑은 교체, 파랑은 추가, 분홍은 삭제 위치**이며, 고친 부분의 강조는 사라집니다. 문서 글씨 크기는 연습 화면에서 조절합니다.

지원 명령과 검색·치환의 제한은 [편집 엔진 지원 범위](sw_design.md#편집-엔진-지원-범위)를 참고하세요. 편집은 메모리 안의 ASCII 문서와 내부 레지스터만 사용합니다.

### Vim CheatSheet

왼쪽 **Vim CheatSheet**에서 이동·편집·검색부터 레지스터·창·설정까지 한글 명령 참조를 볼 수 있습니다. 제목 아래 그림을 누르면 전체 화면으로 열립니다. 화면 맞춤·확대·축소·100% 버튼이나 마우스 휠로 크기를 조절하고, 드래그로 이동하며 Esc로 닫습니다. 기본 화면과 확대 화면 모두 그림을 우클릭해 **PNG 이미지 저장…**을 누르면 원하는 폴더에 원본 해상도로 저장할 수 있습니다.

아래의 명령 카드는 명령이나 설명을 검색하고 분야별로 찾아보세요. 글자 크기를 조절하면 창 폭에 맞춰 카드가 다시 배치됩니다. 실제 Vim의 참조도 포함하며, 앱의 실행 지원 범위와 구분해 안내합니다. 연습 중 열면 현재 시도를 일시정지합니다. **연습으로 돌아가기**로 돌아온 뒤 **연습 재개**를 누르면 이어서 연습할 수 있습니다.

## 조작과 입력

| 조작 | 동작 |
| --- | --- |
| 같은 문제 다시 | 같은 문제와 생성 조건으로 새 시도를 시작합니다. |
| 다른 문제 | 새 문제를 생성합니다. 고정 문서 모드는 원문을 유지하고, 무작위 문서 모드는 원문도 바꿉니다. |
| 문서 선택 | 진행 중 시도를 중단하고 선택한 문서의 새 문제를 준비합니다. |
| 단계 처음으로 | 가이드의 현재 단계 시작으로 돌아갑니다. 아직 입력 전이면 앞 단계로 돌아가며, 누적 입력 수·시간은 유지합니다. |

기술 비중 변경은 다음 새 문제부터 적용합니다. 같은 문제 다시와 문서 길이 변경은 해당 문제의 비중을 유지합니다. 실제 원문에서 선택한 기술만으로 수정 구간을 만들 수 없으면 기존 문제를 보존하고 다른 원문·복합 연습 또는 비중 조정을 안내합니다.

- 영문 입력 모드와 US QWERTY를 기준으로 합니다. 표시용 구분 공백·줄바꿈은 입력하지 않습니다.
- `<Esc>`, `<Enter>`, `<Backspace>`, `<C-r>`는 실제 키입니다. macOS의 `<C-r>`는 **Command가 아닌 Control+R**입니다.
- 타이핑·가이드의 오타는 현재 목표를 유지합니다. 편집의 오타·취소·Backspace·undo/redo도 입력 수에 포함합니다.
- 붙여넣기·드롭·IME 조합 입력·자동 반복은 채점하지 않습니다. 숫자·기호 연습은 감지 가능한 키패드 숫자를 별도 오류로 안내합니다.
- 첫 채점 입력부터 시간을 측정하며 오타 시간도 포함합니다. 일시정지·포커스 상실 시간은 제외하고, 복귀 후 **연습 재개**를 눌러 계속합니다.

키가 예상과 다르게 인식되면 **키 입력 진단**에서 문자·modifier·키패드 여부를 확인하세요.

## 기록과 설정

학습 기록·문서 진행도·개인 기록은 사용자 데이터 폴더의 `vim-key-trainer/training.sqlite3`에 저장합니다. 저장 실패 시 **기록 저장 재시도**로 다시 저장할 수 있습니다. **설정은 앱을 닫으면 초기화됩니다.**

원문과 전체 라이선스는 앱에 포함되어 연습 중 네트워크를 사용하지 않습니다. 출처와 고정 원문 정보는 [문서 목록](src/vim_key_trainer/resources/documents/manifest.json)에 있습니다.

## 개발과 검증

의존성은 [pyproject.toml](pyproject.toml)과 [uv.lock](uv.lock)으로 관리합니다.

```sh
uv run ruff check .
uv run ruff format --check .
uv run mypy src
uv run pytest
```

화면이 없는 환경에서는 `QT_QPA_PLATFORM=offscreen uv run pytest`를 사용합니다. 자동 Qt 검증과 실제 키보드·IME·화면 검증은 구분합니다.

원문 무결성 검사는 `uv run python scripts/fetch_document_corpus.py --verify-only`, 재다운로드는 `--verify-only` 없이 실행합니다.
