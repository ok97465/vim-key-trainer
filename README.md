# vim-key-trainer

Python과 PySide6로 만든 데스크톱 Vim 키보드 연습기입니다. 계정·서버·Vim 설치 없이 로컬에서 동작합니다.

## 설치와 실행

Python 3.12와 [uv](https://docs.astral.sh/uv/getting-started/installation/)를 준비한 뒤 저장소에서 실행합니다.

```sh
uv sync --dev
uv run vim-key-trainer
```

모듈 실행은 `uv run python -m vim_key_trainer`입니다. uv 없이 macOS/Linux에 설치하려면 다음 명령을 사용합니다.

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/python -m vim_key_trainer
```

의존성 선언은 [pyproject.toml](pyproject.toml), 재현 가능한 버전은 [uv.lock](uv.lock)으로 관리합니다.

## 사용할 수 있는 연습

왼쪽 메뉴에서 분야와 레슨을 고른 뒤 **연습 시작**을 누릅니다.

| 분야 | 동작 |
| --- | --- |
| 숫자·기호 | 숫자 무작위, Shift 기호, 괄호쌍, 따옴표·역슬래시, 기타 기호, 혼합의 6종. 기본 20자씩 표시하고 총 100자를 입력하면 완료 |
| Vim 명령 | 전체 혼합·이동·삭제/변경/복사·텍스트 객체·입력/특수키·이력/복합 명령의 6종. 문법에 맞는 명령을 10개씩 계속 생성하고 오른쪽에 짧은 뜻 표시 |
| 문서 수정 | 준비 중. 가이드·자유 풀이 편집 연습은 아직 사용할 수 없음 |

결과에서는 정확도·활성 시간·콤보·별과 개인 기록을 확인합니다. 숫자·기호는 CPM, 명령은 완료 수/분과 명령별 시간을 표시합니다. 설정에서 숫자·기호의 목표 길이·표시량과 연습 글꼴 크기를 조절할 수 있습니다.

**기록과 설정은 앱을 닫으면 초기화됩니다.** Vim 명령은 타이핑 연습이며 문서 편집·매크로·OS 클립보드 동작을 실행하지 않습니다.

## 조작과 입력

| 버튼 | 동작 |
| --- | --- |
| 같은 문제 다시 | 같은 문제 흐름을 처음부터 재시작 |
| 다른 문제 | 유형·설정을 유지하고 새로운 문제 생성 |
| 연습 마치기 | 연속 Vim 연습을 종료하고 결과 표시. 입력 중인 명령은 마친 뒤 종료하며, 이 대기 상태에서만 버튼을 강조 |
| 숫자·기호 선택 / Vim 명령 선택 | 진행 중 시도를 중단하고 해당 분야의 선택 화면으로 이동 |

- 영문 입력 모드와 US QWERTY를 기준으로 합니다. 표시용 구분 공백·줄바꿈은 입력하지 않습니다.
- `<Esc>`, `<Enter>`, `<Backspace>`, `<C-r>`는 실제 키입니다. macOS에서도 `<C-r>`는 Command가 아닌 **Control+R**입니다.
- 오타는 현재 목표를 유지합니다. Backspace는 목표 키로 명시된 경우에만 채점하며 진행을 되돌리지 않습니다.
- 붙여넣기·드롭·IME 조합 입력·길게 누르기의 자동 반복은 채점하지 않습니다. 숫자·기호 연습은 감지 가능한 키패드 숫자를 별도 오류로 안내합니다.
- 첫 채점 입력부터 시간을 측정합니다. 일시정지와 포커스 상실 시간은 제외하며, 돌아온 뒤 **연습 재개**를 눌러 계속합니다.

키가 예상과 다르게 인식되면 **키 입력 진단**에서 문자·논리 키·modifier·키패드 여부를 확인할 수 있습니다.

## 개발과 검증

```sh
uv run ruff check .
uv run ruff format --check .
uv run mypy src
uv run pytest
```

화면이 없는 환경에서는 `QT_QPA_PLATFORM=offscreen uv run pytest`를 사용합니다. 자동 Qt 검증과 실제 키보드·IME·화면 배율 검증은 별도로 수행합니다.
