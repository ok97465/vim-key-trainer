# vim-key-trainer

숫자·기호와 Vim 명령을 익히고, 문서를 목표와 같게 고치는 데스크톱 연습기입니다. 계정이나 Vim 설치 없이 오프라인으로 사용하며, 사용자 파일을 변경하지 않습니다.

## 설치와 실행

Python 3.12와 [uv](https://docs.astral.sh/uv/getting-started/installation/)를 준비합니다.

```sh
uv sync --dev
uv run vim-key-trainer
```

## 연습 방법

왼쪽 메뉴에서 연습을 고른 뒤 **연습 시작**을 누르거나 Enter로 시작합니다. 준비 화면에서는 시간이 흐르지 않으며, 첫 입력부터 측정합니다.

- **숫자·기호**: 숫자, Shift 기호, 괄호, 따옴표를 입력합니다.
- **Vim 명령**: 화면의 명령을 따라 입력합니다. **연습 마치기**로 종료합니다.
- **문서 수정**: 아래 카드에서 연습을 고릅니다.

| 카드 | 연습 내용 |
| --- | --- |
| 일반 문서 연습 | 공개 문서 16개를 바탕으로, 잘못 바뀐 부분을 원문대로 고칩니다. |
| 기술별 문자열 연습 | 숫자·단어·줄 편집 등 6개 기술 카드에서 연습을 고릅니다. 실행 취소·다시 실행은 가이드 전용입니다. |
| Python·C++ | 언어별 12개 프로젝트의 실제 코드에서 300~500줄을 골라 수정합니다. |
| JSON | 서버 주소, 대기 시간, 기능 켜기·끄기 같은 설정값을 수정합니다. |

일반 문서와 코드 카드는 바로 문제를 준비합니다. 일반 문서·Python·C++은 **문서 선택**에서 특정 원문을 고르거나 무작위 선택을 사용할 수 있습니다. 원문과 전체 라이선스는 앱에 포함되어 있습니다. 코드는 실행하지 않습니다.

**가이드**는 안내하는 키를 따라 입력합니다. Python·C++·JSON은 앞쪽 수정부터 시작하며, 오른쪽 목표 문서에서 이번에 고칠 위치를 미리 보여줍니다. **자유 풀이**는 지원하는 명령을 자유롭게 사용해 목표 문서를 만듭니다. 두 모드의 기록은 따로 저장하며, 기준 풀이보다 적은 입력으로 풀어도 정답입니다.

**Vim CheatSheet**에서는 명령 설명과 참고 그림을 볼 수 있습니다. 앱에서 실행할 수 있는 명령은 [지원 범위](sw_design.md#편집-엔진-지원-범위)를 확인하세요.

## 조작과 입력

| 조작 | 동작 |
| --- | --- |
| 같은 문제 다시 | 같은 문제를 처음부터 다시 풉니다. |
| 다른 문제 | 새 문제를 만듭니다. 특정 원문을 선택했다면 유지하고, 무작위 선택이면 원문도 다시 고릅니다. |
| 문서 선택 | 선택한 원문의 새 문제를 준비합니다. |
| 단계 처음으로 | 가이드 단계를 되돌립니다. 누적 입력 수와 시간은 유지합니다. |

- 영문 입력 모드와 US 키보드 배열을 기준으로 합니다. 붙여넣기·드롭·한글 등 조합 입력은 지원하지 않습니다.
- `<Esc>`·`<Enter>`·`<C-r>`는 실제 키로 입력합니다. macOS의 `<C-r>`는 **Command가 아닌 Control+R**입니다.
- 다른 창으로 이동하면 일시정지합니다. 돌아온 뒤 **연습 재개**를 누릅니다.
- 입력이 예상과 다르면 **키 입력 진단**을 사용하세요.

## 기록과 설정

기록은 OS별 사용자 데이터 폴더의 `vim-key-trainer/training.sqlite3`에 저장합니다. 저장 실패 시 **기록 저장 재시도**를 누를 수 있습니다. **설정은 앱을 닫으면 초기화됩니다.**

업데이트로 기록 버전이 바뀌면 이전 학습 기록·진행도·최고 기록·수집 현황을 모두 초기화합니다.
