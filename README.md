# vim-key-trainer

숫자·기호와 Vim 명령을 익히고, 문서를 목표와 같게 고치는 데스크톱 연습기입니다. 계정이나 Vim 설치 없이 오프라인으로 사용하며, 사용자 파일을 변경하지 않습니다.

## 설치와 실행

Python 3.12와 [uv](https://docs.astral.sh/uv/getting-started/installation/)를 준비합니다.

```sh
uv sync --dev
uv run vim-key-trainer
```

## 연습 방법

왼쪽 메뉴에서 연습을 고른 뒤 **연습 시작**을 누르거나 Enter로 시작합니다. 준비 화면에서는 시간이 흐르지 않으며, 첫 입력부터 측정합니다.

- **숫자·기호**: 숫자, Shift 기호, 괄호, 따옴표를 입력합니다.
- **Vim 명령**: 화면의 명령을 따라 입력합니다. **연습 마치기**로 종료합니다.
- **문서 수정**: 아래 카드에서 연습을 고릅니다.

| 카드 | 연습 내용 |
| --- | --- |
| 일반 문서 연습 | 공개 문서 16개를 바탕으로, 잘못 바뀐 부분을 원문대로 고칩니다. |
| 기술별 문자열 연습 | 숫자·단어·줄 편집 등 6개 기술 카드에서 연습을 고릅니다. 실행 취소·다시 실행은 가이드 전용입니다. |
| Python·C++ | 언어별 12개 프로젝트의 실제 코드에서 300~500줄을 골라 수정합니다. |
| JSON | 서버 주소, 대기 시간, 기능 켜기·끄기 같은 설정값을 수정합니다. |

일반 문서와 코드 카드는 바로 문제를 준비합니다. 일반 문서·Python·C++은 **문서 선택**에서 특정 원문을 고르거나 무작위 선택을 사용할 수 있습니다. 원문과 전체 라이선스는 앱에 포함되어 있습니다. 코드는 실행하지 않습니다.

**가이드**는 안내하는 키를 따라 입력합니다. Python·C++·JSON은 앞쪽 수정부터 시작하며, 오른쪽 목표 문서에서 이번에 고칠 위치를 미리 보여줍니다. **자유 풀이**는 지원하는 명령을 자유롭게 사용해 목표 문서를 만듭니다. 두 모드의 기록은 따로 저장하며, 기준 풀이보다 적은 입력으로 풀어도 정답입니다.

자유 풀이에서는 일반 연습과 폭탄 도전 모두 **자유 복구 게이지**를 표시합니다. 처음 문서의 차이를 어떤 순서·명령으로 고쳐도 Normal 모드에서 부분 복구의 절단·낙하·성공음이 나옵니다. 여러 곳을 한 명령으로 고치면 함께 반응합니다. 삭제할 때는 남겨야 할 단어도 목표와 맞아야 성공으로 표시합니다. 해결한 위치에는 체크가 남고, undo로 되돌리면 현재 진도와 체크도 줄어듭니다. 같은 위치의 성공 효과는 한 시도에서 한 번만 나오며, 누적 복구 수에 따라 색과 소리가 커집니다. 새로 생긴 문서 차이는 별도로 고쳐야 하고 전체 문서가 목표와 일치해야 완료됩니다.

**Vim CheatSheet**에서는 명령 설명과 참고 그림을 볼 수 있습니다. 앱에서 실행할 수 있는 명령은 [지원 범위](sw_design.md#편집-엔진-지원-범위)를 확인하세요.

## 폭탄 도전과 작업실

문서 수정 준비 화면에서 **폭탄 도전**을 고르면 이동부터 수정까지 한 구간씩 제한시간 안에 해체합니다. **여유·보통·도전** 난이도와 **시간 초과 자동 수정**을 선택할 수 있습니다. 첫 입력부터 시간이 흐르며, 일시정지·CheatSheet·설정 열람 뒤에는 직접 재개합니다.

- 시간 내 성공하면 칼날 잔상과 함께 글자 조각이 갈라져 떨어지고 성공 도장이 남습니다. 시간 초과는 별도 파손 효과와 복구 표식으로 구분합니다. 자동 수정을 끄면 실패 구간을 직접 마무리할 수 있습니다.
- 결과에서 직접 해결·시간 초과·자동 복구를 따로 확인하고 **놓친 구간 복수전**으로 다시 연습합니다. 시간 초과가 섞이면 전체 클리어·별·완료 수집 보상은 지급하지 않습니다.
- 심지 불꽃이 폭탄 쪽으로 다가오며, 남은 시간이 적으면 테두리·캐릭터가 반응합니다. **기록 대결**은 같은 문제·조건의 내 해체 진도와 최고 기록을 두 주자 트랙으로 보여줍니다. 자유 풀이는 문서 전체 제한시간만 사용하며, 시간 초과 후에는 자동 수정 없이 추가 학습을 계속합니다. 실행 취소 과제에는 폭탄 도전을 제공하지 않습니다.
- 연속 해체를 이어 가면 효과가 단계적으로 커지고, 간발의 해체·복수전 성공에는 별도 표식이 나옵니다. 마지막 해체는 결과 화면의 파편과 점수 연출로 이어지며 바로 재도전할 수 있습니다.
- 자유 풀이의 부분 복구는 제한시간·해체 점수·완료 보상을 바꾸지 않습니다. 시간이 끝나는 순간에는 앱 창 가장자리에 은은한 빛과 작은 시계 안내가 한 번 나타나 소리 없이도 알 수 있습니다. 상태줄의 시계·**시간 종료 · 계속 연습** 표시는 이후에도 남습니다. **실패음** 설정을 켜면 부드러운 하강음도 들을 수 있습니다. 추가 학습에도 부분 복구 효과는 이어지고, 일반 자유풀이 완료에는 별·입력 횟수·시간을 보여주는 피날레가 나옵니다.
- 분야 메뉴의 **오늘의 미션**은 로컬 날짜별 고정 문제, **보스 문서**는 세 가지 기술을 조합한 별도 문제입니다. 보스는 구간 진행에 따라 균열과 단계가 표시됩니다. 준비 화면에서 선택한 보너스 목표는 기본 완료와 별도로 평가합니다.
- **나의 작은 작업실**은 문서 수집에 따라 밝아집니다. 서로 다른 연습을 완료하면 고양이 폭탄·심지 색·성공 도장을 해금하고 짧은 조명·책 장식 연출로 알려줍니다. 같은 유형·원문을 반복해도 해금 수는 늘지 않습니다.

**연습 설정 → 성공음·실패음**을 켜면 절단·저음 타격·파편 잔향이 이어지는 해체음과 금속성 실패음을 들을 수 있습니다. 기술·연속 해체에 따라 음색이 바뀝니다. 기본은 무음이며 음량·초읽기·심지·박동음·화면 효과·모션 줄이기를 조절합니다. 모션 줄이기는 칼질과 파편 대신 정적인 표식과 위험 테두리를 표시합니다. 연출과 꾸미기는 문서·입력·제한시간·점수를 바꾸지 않습니다.

선호 창 크기는 Qt 논리 픽셀 기준 `1440×900`입니다. 작은 작업 영역에는 창을 맞추고 조작 버튼을 여러 줄로 배치합니다. 문서 두 개는 각각 가로·세로 스크롤할 수 있습니다.

## 조작과 입력

| 조작 | 동작 |
| --- | --- |
| 같은 문제 다시 | 같은 문제를 처음부터 다시 풉니다. |
| 다른 문제 | 새 문제를 만듭니다. 특정 원문을 선택했다면 유지하고, 무작위 선택이면 원문도 다시 고릅니다. |
| 문서 선택 | 선택한 원문의 새 문제를 준비합니다. |
| 단계 처음으로 | 가이드 단계를 되돌립니다. 누적 입력 수와 시간은 유지합니다. |

- 영문 입력 모드와 US 키보드 배열을 기준으로 합니다. 붙여넣기·드롭·한글 등 조합 입력은 지원하지 않습니다.
- `<Esc>`·`<Enter>`·`<C-r>`는 실제 키로 입력합니다. macOS의 `<C-r>`는 **Command가 아닌 Control+R**입니다.
- 다른 창으로 이동하면 일시정지합니다. 돌아온 뒤 **연습 재개**를 누릅니다.
- 입력이 예상과 다르면 **키 입력 진단**을 사용하세요.

## 기록과 설정

기록은 OS별 사용자 데이터 폴더의 `vim-key-trainer/training.sqlite3`에 저장합니다. 저장 실패 시 **기록 저장 재시도**를 누를 수 있습니다. 실패 당시 문서는 현재 결과 화면까지만 메모리에 보관하며, 원시 입력열은 저장하지 않습니다.

문서 수정의 마지막 **가이드/자유 풀이·일반 연습/폭탄 도전·여유/보통/도전** 선택은 다음 문제와 앱 재실행 때 복원합니다. 자유풀이를 지원하지 않는 실행 취소 과제는 해당 과제만 가이드로 열며, 다음 지원 과제에서는 원래 선택을 복원합니다.

이 선택과 자동 수정·문서 글씨 크기·기록 대결 표시·소리/화면 효과·꾸미기는 OS별 설정 폴더의 `vim-key-trainer/settings.json`에 저장합니다. 나머지 연습 설정은 앱 종료 시 초기화됩니다. 설정 손상·버전 불일치는 기본값과 안내로 처리합니다. 설정 형식은 버전 2이며 이전 형식의 설정은 기본값으로 초기화합니다. 학습 기록 저장 버전과는 별개입니다.

업데이트로 기록 버전이 바뀌면 이전 학습 기록·진행도·최고 기록·수집 현황을 모두 초기화합니다.
