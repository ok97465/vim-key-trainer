# 아이콘 관리

| 파일 | 용도 |
| --- | --- |
| `ok97465.png` | 제목 표시줄과 작성자 표시 |
| `vim-key-trainer.png` | 앱과 바탕화면 바로가기 |
| 같은 이름의 `.ico` | Windows용 아이콘 |

PNG는 정사각형·투명 배경을 유지하며, 기본 색상은 남색 `#10151d`와 연두색 `#c3ef85`입니다. 작은 크기에서도 글자와 모양을 알아볼 수 있어야 합니다.

PNG를 교체하면 저장소 루트에서 ICO를 다시 생성합니다.

```sh
uv run python scripts/export_icons.py
```

ICO에는 16~256px의 여러 해상도를 포함합니다.
